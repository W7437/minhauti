# MinhaUTI — Escores v2

Módulo integrado ao MinhaUTI.

Principais recursos:
- Busca por texto com sugestão por nome, sigla ou situação clínica.
- Sugestões baseadas nas hipóteses diagnósticas e alertas do checklist do leito ativo.
- Leitura apenas do armazenamento local do navegador.
- Pré-preenchimento de parâmetros disponíveis no leito, sempre com aviso para conferência.
- Escores implementados:
  - NEWS2 (SpO2 Scale 1)
  - qSOFA
  - SOFA
  - CURB-65
  - sPESI
  - Wells para TEP
  - PERC
  - HEART
  - TIMI UA/NSTEMI
  - BISAP
  - Glasgow Coma Scale
  - SIRS
- Fontes primárias/oficiais disponíveis no próprio formulário.
